% QICLean chapter router. Order follows M. Wolf, "Quantum Channels &
% Operations: A Guided Tour" (Notes/WolfNoteTexSource/ in the source
% repository this content was extracted from). Chapter files are numbered
% sequentially in the order they appear below (chNN_ = this volume's own
% chapter NN, not TNLean's).
%
% Every chapter file lives directly under chapter/: there is no separate
% "Appendices" part and no ft_mps/full_only split. TNLean organizes its own
% blueprint into a shared Fundamental-Theorem-of-MPS volume ("ft_mps") and a
% remaining-results volume ("full_only"), each with its own front matter and
% appendix numbering; that split is a paper-volume artifact of TNLean's
% build, not a property of the mathematics. Content that TNLean filed as a
% "Supporting Results" appendix to one of its chapters is filed here as a
% same-chapter continuation instead -- a same-named chNN_..._supporting_
% results.tex file \input immediately after that chapter's main content, so
% it appears as further sections of the one chapter Wolf's own numbering
% gives the material, with no separate appendix part or numbering track.
%
% Wolf chapter -> file mapping (see the extraction report for the full
% per-file classification and the 61-file move list):
%   Ch.1  Deconstructing Quantum       -> ch01_{states,positive_maps,
%                                          spectrum_and_wigner} (input via
%                                          ch01_deconstructing_quantum, the
%                                          volume's opening chapter)
%   Ch.2  Representations              -> ch02_channels_{positive_map_and_
%                                          channel_foundations,
%                                          rectangular_kraus_maps},
%                                          ch03_channel_representations_*
%                                          (including the former auxiliary
%                                          chapter's Choi foundations and
%                                          no-information-without-disturbance
%                                          sections, folded in as this
%                                          chapter's opening material)
%   Ch.3  Positive, but not completely -> ch04_positive_not_cp_* (except
%                                          kramers_degeneracy, which stays
%                                          in TNLean)
%   Ch.5  Operator Inequalities        -> ch05_schwarz_* (including the
%                                          former auxiliary chapter's
%                                          abstract-domains-and-order
%                                          section), ch06_operator_convexity_*
%   Ch.6  Spectral properties          -> ch02_channels_{peripheral_spectrum_
%                                          and_primitivity,transfer_map_
%                                          foundations}, ch07_qpf* (including
%                                          the former auxiliary chapter's
%                                          exponential-positivity and
%                                          ergodicity section),
%                                          ch08_spectral_ft_peripheral_cyclic,
%                                          ch08_spectral_supporting_results,
%                                          ch09_channel_asymptotics_*
%   Ch.7  Continuous one-parameter
%         semigroups                   -> ch11_semigroup_*
%   Ch.8  Measures for distances and
%         mixedness                    -> ch12_entropy_*,
%                                          ch09_channel_asymptotics_
%                                          {jordan_block_power,
%                                          upper_triangular_power}
%
% No Wolf Ch.4 (Convex Structure) or Ch.9-11 (Symmetries, Special channels,
