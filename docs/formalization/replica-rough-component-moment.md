# A rough exponential estimate for an excitation component

The actual density on the good copies retains the five independent factors
Q, Y, V, C and R and traces only the bad copies of the same excitation
component w. The physical deficit is G = F_Q + F_V − F_Y. Both auxiliary
merge deficits commute with G, and the actual density is supported on its
closed nonnegative spectral subspace.

For 0 ≤ a ≤ 1/2, spectral compression removes G from the exponential trace.
The actual two-merge moment then bounds the remaining trace by

\[
\frac{(m+1)^{(|Q|\,|C|)^2}+(m+1)^{(|V|\,|R|)^2}}2\,\|w\|^2,
\qquad m=|B^c|.
\]

The mass is retained literally. No normalization or nonzero-component
hypothesis is imposed, and no positivity of G on the whole space is used.
The one-copy physical vector is unit, and the original vector is fixed by
the actual simultaneous physical and auxiliary copy permutations. These
are the only state assumptions; the support and moment identities are
derived for the actual density.

This proves the rough exponential pairing used in the September 24, 2026
area-law manuscript, Section 7, lines 513–555. It remains an auxiliary
estimate before the inverse metric and the good auxiliary scalar factor
are introduced. It does not establish the full component inverse comparison.
