# A canonical sample whose size depends on its input rank

The requested sample size may be any fixed function of the actual input
matrix rank. The canonical sampler continues to use the same finite product
of unitary groups and the coordinate at that actual rank. Its retained
dimension is the minimum of the requested size and the rank. In particular,
the choice Q/(2D^2), with natural quotient, requires no new sampler.

Four supporting consequences show that the actual sample projection,
fixed-family image projection, collective-trim projection and true regional
viability event remain Borel. The proof restricts to each rank stratum,
where the requested size is constant, and reuses the existing canonical
sampling and trimming results. Every fixed-size theorem changed by this
generalization remains an active constant-function corollary.

The original exterior tensor factor is retained, so the fixed target may
be entangled with it. No measurable arbitrary basis, supplied event
measurability or jointly chosen measurable hull is assumed.
