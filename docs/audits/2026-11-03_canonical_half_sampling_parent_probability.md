# True probability for the same complete stopped-resampling parent

The probability theorem consumes the fixed-coefficient stopped-loop result
once. It retains exactly the same finite product Haar law, prescribed seed
extension, original-target event, stopping coefficient, family and reference.
That true event supplies viability of the actual terminal range, so the
previous deterministic theorem applies to the same complete native parent.
The true final-parent `3/200`-viability event is Borel and its failure measure
is at most `rounds * eta / (N+2)^a`. On the same loop event, the last UNTRIMMED
image retains error `Delta/(91/100)^2` for every improving target. No
intersection of center-indexed events is assumed measurable.

The coefficient is given together with the explicit numerical bootstrap
threshold inequality. It can therefore be chosen by the scalar theorem
before chain-carrier types, then used unchanged in each instance. There
is no additional one-step success, section or final-parent success premise.
The original-to-improving-target error already needed by the loop implies
the weaker transfer bound needed by the terminal step. All actual ranks
remain bounded by the initial rank on every history, and the final image
and output dimensions retain their bounds by family cardinality times the
actual terminal rank. The exact reference budget uses the number of cuts,
not a substituted image-dimension ceiling.

The theorem is for one repeated-resampling parent;
recursive-tree probability and running time are separate obligations.
