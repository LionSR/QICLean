# The actual finite-family image projection

The existing joint column support is now identified with the actual
orthogonal projection onto the sum of the operator images of a subspace,
in Euclidean coordinates. Thus the original subspace operation, rather
than a supplied comparison space, has a Borel actual projection when the
input actual projection is Borel.

The proof first transports the existing joint-support range identity
through the ordinary-to-Euclidean coordinate equivalence. This equivalence
preserves sums of subspaces. For fixed operators F_i and the actual
projection P_S, the range of F_i P_S is exactly F_i S. The existing support
is an orthogonal projection, so equality of these actual ranges identifies
it with the actual projection onto their sum. The Borel conclusion then
uses the existing measurable joint-family support.

These are auxiliaries to ALVV, arXiv:1602.08828v2, Lemma l:er, lines
597–622, and the interleaved family-and-trim operation at lines 1668–1670.
Empty families and zero spaces are included. No rank, nonzero-space,
viability, or desired-event-measurability hypothesis is introduced.
