# True regional viability and tensor-merge measurability

The original viability event is Borel for a constructed local subspace
whose actual orthogonal projection is Borel, with an arbitrary fixed
target in the local space tensored with its whole exterior. The exact
sampled, improved and collectively trimmed subspace from the preceding
canonical construction satisfies this premise without a supplied event
measurability or comparison-target hypothesis.

The geometric identity is exact: the actual projection of a tensor product
of subspaces is represented by the Kronecker product of the factor
projections in the prescribed product coordinates. A fixed relabeling of
coordinates relabels the actual projection by the same row and column
equivalence. Both operations are continuous on finite matrices. The proofs
reuse the existing tensor-product projection and matrix-action intertwining
identities. They require no rank, gap, uniqueness or nonempty-space premise.

For viability, tensor the local candidate with the whole exterior space,
carry the fixed target through the fixed tensor-coordinate isometry, and
apply the proved true-closeness event test. Closeness invariance under
isometries identifies this event exactly with the original IsViable
predicate. The target can be entangled. Zero-dimensional factors and
arbitrary real errors are included. The arbitrary exterior decidable
equality instance is local to the proof, not a theorem hypothesis.

The existing regional tensor merge is also proved to have a Borel actual
projection. Its original union-configuration equivalence is retained. A
separate TN companion specializes this to the existing adjacent-interval
merge and its true viability event for the same global target in the
parent/exterior coordinates.
