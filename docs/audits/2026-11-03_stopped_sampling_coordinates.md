# Range coordinates for stopped half-dimensional sampling

The family-image identity applies to arbitrary input matrices, not merely to orthogonal projections. If I is the fixed input isometry and F_i is the rectangular matrix of A_i I, the existing joint column support of (F_i P)_i has range equal to the sum of A_i(I(range P)). This is the common coordinate identity used by the stopped sampling step and the terminal native-parent trim.

The actual projection onto range P is the existing singleton-family support. Its Borel dependence, followed by the fixed coordinate and tensor identifications, gives the true original-target viability event for arbitrary Borel matrix inputs. No selected basis, measurable success hull, rank, nonzero or projection premise is introduced.
