# The low-density entropy coefficient at fixed bandwidth

The numerical entropy contribution from the initial viable space and the actual dyadic filter counts is bounded by `K_eta / v` times `(1 + log q + log(1 + 1/v))^3`. The coefficient is explicit and depends only on the fixed bandwidth and two preceding universal constants. It is independent of the length, local dimension, target deficit and low-energy multiplicity.

This is an auxiliary estimate for Arad, Landau, Vazirani and Vidick, arXiv:1602.08828v2, Theorem `thm:al-ld`, lines 1096–1105. The actual physical entropy theorem must supply the preceding numerical profile; this scalar estimate alone is not an area-law theorem.
