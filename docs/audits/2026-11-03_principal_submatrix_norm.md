# Principal submatrix contraction: independent matrix-norm ownership

The inequality `Matrix.l2_opNorm_principal_submatrix_le` concerns an arbitrary square complex matrix and an injective coordinate inclusion. It requires neither a Jordan form nor positivity. Its former owner, `Analysis/JordanBlockComparison.lean`, was therefore unnecessary for a consumer using only coordinate compression.

The declaration now belongs to `Analysis/PrincipalSubmatrixNorm.lean`. Its fully qualified name, signature and entire proof text are unchanged. The old definition is removed, and `JordanBlockComparison` imports the new owner. Every existing public signature of that module is preserved; there is no duplicate declaration or forwarding theorem. The new owner imports only the existing matrix-frame estimate. The generated analysis imports were regenerated by the repository script.

The mathematical blueprint statement is now the general lemma `lem:principal_submatrix_norm` in the coherent-frame section. The Jordan-power entry retains its actual Jordan identities and cites that general lemma.
