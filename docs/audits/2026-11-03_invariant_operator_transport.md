# The same operator under powers and unitary coordinates

The generic estimates retain one actual continuous operator K and one actual target T. If K preserves T and its orthogonal complement, has minimum gain one on T and complementary squared bound Delta, its r-th power has the same invariance and gain, with bound Delta^r. A surjective linear isometry transports these bounds to the exact conjugate I K I^{-1} and target I(T). No common eigenbasis, positivity, scalar action or identity action on the target is assumed.

The actual tensor decomposition gives actual simultaneous ordered words by the existing finite tensor-power identity. Applying the existing viable-subspace error-reduction theorem to this powered decomposition gives dimension at most |I|^r dim S and error Delta^r/(1-delta)^2. This is the algebraic step needed when a fixed global filter is represented on a different retained interval. It does not transport viability between unrelated tensor splits; the new viable-family estimate comes from the newly derived tensor decomposition.
