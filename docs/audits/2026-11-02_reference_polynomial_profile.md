# Polynomial bounds for the numerical refinement parameters

The reference logarithmic estimate now implies an integer-power bound with constants independent of the accuracy factor. The inverse refinement and reference accuracies are bounded by cubic and quartic powers of a common bound for the spectral width and inverse requested error. The lower gap alone enters these two coefficients.

These are auxiliary estimates for the final refinement in Arad, Landau, Vazirani and Vidick, arXiv:1602.08828v2, lines 1801–1817. They do not yet assert a uniform polynomial bound for the complete physical tree output or a computational running time.

The seven public numerical statements pass strict elaboration with both automatic implicit options disabled, the package synthesis-depth limit, Mathlib standard linters and warnings treated as errors. Imported foundation inspection reports only `propext`, `Classical.choice` and `Quot.sound`. The temporary inspection source was deleted. The ordinary integrated build and declaration checks remain required after adoption.
