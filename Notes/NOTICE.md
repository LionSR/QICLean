# Notice for the `Notes/` directory

This directory contains the LaTeX sources (`WolfNoteTexSource/`) and PDF
chapters (`WolfNotePDF/`) of Michael M. Wolf's lecture notes *Quantum
Channels & Operations: Guided Tour*, the primary source that this library
formalizes and whose chapter structure the blueprint follows. They are
included as reference material for the formalization, with the author's
permission.
